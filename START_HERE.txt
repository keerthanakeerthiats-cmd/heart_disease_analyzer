================================================================
TROUBLESHOOTING
================================================================

Problem: "kaggle.json NOT FOUND"
Solution: Make sure you downloaded it from Kaggle.com
          Check your Downloads folder

Problem: Script stops or shows errors
Solution: Make sure Python is installed
          Run: python --version (should show Python 3.x)

Problem: Training takes too long
Solution: You can skip training (type 'n' when asked)
          App will work but predictions won't be accurate

Problem: Can't open http://localhost:5000
Solution: Make sure app.py is running
          Look for "Running on http://127.0.0.1:5000" message
