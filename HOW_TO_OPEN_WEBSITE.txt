================================================================
TROUBLESHOOTING
================================================================

Problem: "python is not recognized"
------------------------------------
Solution: Python not installed or not in PATH
          Download Python from: python.org
          During install, check "Add Python to PATH"


Problem: Black window closes immediately
-----------------------------------------
Solution: There's an error
          Right-click OPEN_WEBSITE.bat → Edit
          Check error message
          Usually means: missing dependencies
          
          Fix: Double-click setup.bat first


Problem: Browser doesn't open
------------------------------
Solution: Manually open browser and type:
          http://localhost:5000


Problem: "This site can't be reached"
--------------------------------------
Solution: Check the black window for errors
          Make sure it says "Running on http://127.0.0.1:5000"
          If you see errors, dependencies may be missing
