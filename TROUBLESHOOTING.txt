================================================================
         TROUBLESHOOTING GUIDE - Can't Open Website
================================================================

STEP 1: Run Diagnostic Tool
============================
Double-click: DIAGNOSE.bat

This will automatically:
✓ Check if Python is installed
✓ Check if all files are present
✓ Install missing dependencies
✓ Identify the problem
✓ Try to start the website

Wait for it to complete and see what error it shows.


================================================================
COMMON PROBLEMS & SOLUTIONS
================================================================

PROBLEM 1: "Python is not recognized"
======================================
CAUSE: Python not installed or not in system PATH

SOLUTION:
1. Download Python from: https://www.python.org/downloads/
2. Run installer
3. ⚠️ IMPORTANT: Check "Add Python to PATH" box
4. Click Install
5. Restart computer
6. Try again


PROBLEM 2: Black window appears then closes immediately
========================================================
CAUSE: Error in app.py or missing dependencies

SOLUTION:
1. Double-click: DIAGNOSE.bat
2. It will install missing packages automatically
3. Try OPEN_WEBSITE.bat again


PROBLEM 3: "ModuleNotFoundError: No module named 'flask'"
==========================================================
CAUSE: Flask not installed

SOLUTION:
Open Command Prompt and run:
    pip install flask flask-cors pillow numpy opencv-python

Or double-click: setup.bat


PROBLEM 4: Browser opens but shows "This site can't be reached"
================================================================
CAUSE: Server didn't start properly

SOLUTION:
Check the black window for error messages.

Common errors:

  A) "ModuleNotFoundError"
     Fix: pip install [missing module name]

  B) "Port 5000 is already in use"
     Fix: Close other applications using port 5000
          Or change port in app.py (see below)

  C) "Permission denied"
     Fix: Run as Administrator
          Right-click OPEN_WEBSITE.bat → Run as administrator


PROBLEM 5: TensorFlow errors
=============================
CAUSE: TensorFlow not compatible with Python 3.13

SOLUTION:
The app works without TensorFlow initially!
Models will give random predictions until trained.

To fix properly:
1. Install Python 3.11 (not 3.13)
2. Run: pip install tensorflow


PROBLEM 6: Website shows but can't upload images
=================================================
CAUSE: uploads/ folder missing or permission issues

SOLUTION:
1. Make sure uploads/ folder exists in project directory
2. Check folder permissions (should allow read/write)


================================================================
HOW TO CHANGE PORT (If Port 5000 is Busy)
================================================================

If another app is using port 5000:

1. Right-click app.py → Open with → Notepad
2. Scroll to the very bottom
3. Find this line:
   app.run(debug=True, host='0.0.0.0', port=5000)

4. Change 5000 to 5001:
   app.run(debug=True, host='0.0.0.0', port=5001)

5. Save file
6. Now visit: http://localhost:5001

STILL NOT WORKING?
================================================================

Follow these steps IN ORDER:

1. Double-click: DIAGNOSE.bat

2. Take a screenshot of errors shown

3. Common fixes to try:
   a) Restart computer

   c) Disable antivirus temporarily

   → Run: pip install XXX

6. If nothing works:

ERROR MESSAGES DECODER
================================================================

Error: "ModuleNotFoundError"
→ Missing Python package
→ Fix: pip install [package name]

Error: "Address already in use"
→ Port 5000 busy
→ Fix: Change port or close other apps

Error: "Permission denied"
→ Need administrator rights
→ Fix: Run as administrator

Error: "No such file or directory"
→ Wrong folder location
→ Fix: Navigate to correct folder

Error: "Python is not recognized"
→ Python not installed
→ Fix: Install Python

Error: "Syntax error"
→ Code file corrupted
→ Fix: Re-download files
